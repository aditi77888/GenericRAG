# Generic RAG Framework

A modular Retrieval-Augmented Generation (RAG) framework built completely from scratch without LangChain.

## Features

- Modular document loaders
- OCR support
- Multiple chunking strategies
- Configurable embedding models
- Multiple vector databases
- Multi-LLM support
- Agents
- FastAPI backend
- Streamlit UI
- Benchmarking
